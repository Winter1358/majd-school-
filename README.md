# سامانه مدیریت مدرسه - مرحله ۱

## اجرا روی GitHub Pages
1. یک مخزن (Repository) جدید بسازید و همه فایل‌ها را آپلود کنید.
2. Settings > Pages > Source: Deploy from a branch > main / root
3. آدرس سایت را باز کنید.

## ورود اولیه (بلافاصله رمز را عوض کنید)
- مدیر کل: superadmin / Admin@123
- برنامه‌نویس: dev / Dev@12345

## نکته مهم
در این مرحله اطلاعات در مرورگر (localStorage) ذخیره می‌شود و فقط برای تست است.
برای استفاده واقعی، مرحله بعد اتصال به بک‌اند (مثل Supabase/Firebase) لازم است.
